# User Custom Behavior Rules

- **D盘操作规则**：用户要求以后所有的开发、测试、脚本执行、dump 缓存以及临时文件写入操作，**一律只在 D 盘的工作目录或 D 盘临时目录中进行**。绝对不要在 C 盘（例如 `C:\Users\30406\...` 或者是系统的 `brain` 目录下）创建或写入任何非必须的临时文件或脚本。
- **调试日志与证据积累规则**：在后续的代码开发、修改及真机测试验证过程中，必须持续丰富调试日志（`docs/debug-log.md`）。在日志中记录调试细节时，务必补充核心代码片段（代码截图/代码块对比）以及真实测试输出日志、串口日志等作为验证证据。
