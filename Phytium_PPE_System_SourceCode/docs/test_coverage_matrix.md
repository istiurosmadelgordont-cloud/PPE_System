## 3. 测试用例详情 (对应功能测试表.xlsx)

### TC-01: USB摄像头拉流测试
- **前置条件**: 物理 USB 摄像头已成功挂载
- **步骤**: 1. 启动智能监控大屏系统；2. 观察视频源拉流帧率及 CPU 绑核规则（Core 0）。
- **实测结果**: Pass。实时拉流帧率稳定在 11.4 FPS 左右，拉流控制线程静态绑定于 Core 0 小核运行。

### TC-02: 视频源无感热切换测试
- **前置条件**: 程序正常运行，摄像头已连接，本地包含测试视频
- **步骤**: 1. 在 Qt 界面点击“导入录像”导入 MP4 文件；2. 观察视频播放完毕后的系统反应。
- **实测结果**: Pass。画面切换平滑无缝；视频播放完毕后终端打印回退提示，1秒内成功切回物理摄像头画面。

### TC-03: 多线程无锁数据传输测试
- **前置条件**: 系统多线程高并发运行
- **步骤**: 1. 开启 htop 监控 CPU 状态；2. 让系统高负荷连续运行超 4 小时，观察多线程并发状态。
- **实测结果**: Pass。基于原子屏障 of SPSC 无锁环形队列运行良好，大核算力全开（达 98%），满载运行 4 小时无假死或内核态阻塞。

### TC-04: PPE 八类目标检测精度测试
- **前置条件**: 输入包含远处“手套/眼镜/安全帽”等小目标的画面
- **步骤**: 1. 让受试人员站在距摄像头 3-5 米外；2. 观察系统对微小特征的检出率。
- **实测结果**: Pass。QAT INT8 模型推理精度优良，远处手套等微小特征未被截断抹平，置信度稳定在 0.52 以上。

### TC-05: 复杂遮挡目标追踪测试
- **前置条件**: 开启 ByteTrack 追踪模块
- **步骤**: 1. 安排两名工人在镜头前交叉走动；2. 安排工人短暂走到障碍物后方（遮挡 15 帧以上）再走出。
- **实测结果**: Pass。复杂遮挡重现后，卡尔曼滤波成功捞回原 ID 并继续追踪，状态防抖正常，ID 未频繁跳变。

### TC-06: 违规报警物理阻断测试
- **前置条件**: 1号小核裸机固件已加载，硬件连接正常
- **步骤**: 1. 模拟工人摘下安全帽（违规），观察从核蜂鸣器反应；2. 模拟工人重新戴上安全帽（合规），观察从核状态。
- **实测结果**: Pass。经过示波器精密测量，跨核联动端到端时延仅为 **42.84 微秒 (μs)**，远低于 1ms 的设计阈值，实现微秒级瞬时安全阻断动作。详见 [06_主从核联动延迟测试报告](file:///d:/飞腾派/CICC1004607+初赛+技术数据(代码类)/ppe4-28/Phytium_PPE_System_SourceCode/docs/06_主从核联动延迟测试报告.md)。

### TC-07: 灾害环境硬中断与监测测试
- **前置条件**: OpenAMP 底层通信链路已就绪，从核已接入火焰、有害气体及温湿度传感器并满载运行。
- **步骤**: 1. 物理触发火焰与有害气体传感器，向从核注入硬件中断与电平变化数据；2. 模拟 50ms 内的临界电平抖动，并读取 AHT20 温湿度传感器数据，观察界面显示。
- **实测结果**: Pass。火焰与有害气体硬中断抢占机制测试通过。在 50ms 模拟抖动下无闪烁；温湿度环境数据大屏实时刷新无误。

### TC-08: 零拷贝监控大屏测试
- **前置条件**: UI 界面处于监控状态
- **步骤**: 1. 启动视频拉流，观察监控大屏画面是否有撕裂或相位延迟。
- **实测结果**: Pass。零拷贝渲染极大地降低了内存拷贝开销，视频在大屏幕原位渲染平滑流畅，帧率稳定在 11.4 FPS。

### TC-09: 硬件状态自视看板测试
- **前置条件**: 系统处于正常运行状态
- **步骤**: 1. 核对侧边栏的 CPU 温度和负载百分比，与底层终端 htop 监控值对比。
- **实测结果**: Pass。硬件监控看板数据刷新机制正常，CPU 负载与温度动态展示无误，与底层 htop 实测完全一致。

### TC-10: 违规异步抓拍落盘测试
- **前置条件**: 触发违规事件
- **步骤**: 1. 模拟违规事件发生，观察专职 I/O 线程在后台执行 JPEG 编码和 CSV 写入时的 UI 流畅度。
- **实测结果**: Pass。违规抓拍与日志异步写盘机制运行良好，数据不丢失，且消除了 I/O 阻塞对前台 GUI 帧率的影响。

### TC-11: 磁盘防洪自清洁机制测试
- **前置条件**: violations_data 目录空间报警阈值已配置
- **步骤**: 1. 向 violations_data 强行拷入大文件，使磁盘分区占用达到 85% 以上，触发一次新违规。
- **实测结果**: Pass。分区占用率超 85% 后自动触发自清洁机制，成功按时间戳升序清理 1500 张旧照片，新抓拍顺利写入。

### TC-12: 主从心跳通信测试
- **前置条件**: 心跳监控线程 heartbeat_task 已启动，周期 500ms
- **步骤**: 1. 监测正常运行时从核对心跳包的应答状态；2. 在主核人为挂起 AI 业务线程，观察心跳是否丢失并验证从核报警动作。
- **实测结果**: Pass。心跳线程真机测试通过。主核人为挂起后，从核在 2s 内准确检测并报警，且串口成功打印失联日志。

### TC-13: 看门狗(WDT)容错与自愈测试
- **前置条件**: 飞腾底层 fwdt 硬件看门狗驱动已加载，从核 Fail-Safe 自愈逻辑处于监听状态。
- **步骤**: 1. 模拟主核异常挂死导致心跳中断，监测从核接管与看门狗冷重启反应。
- **实测结果**: Pass。主核宕机后从核瞬间接管驱动蜂鸣器长鸣，WDT 超时 10s 后芯片执行硬件 cold reset 成功冷重启并恢复自愈。

### TC-14: DeepSeek AI 安全建议测试
- **前置条件**: 系统网络畅通且配置了 DeepSeek API Key，滑动窗口与 UI 日志渲染激活。
- **步骤**: 1. 触发违规，观察 DeepSeek 异步调用、整改建议及 UI 字符表现（规避表情符号）；2. 在 10s 内连续触发多次违规，观察数量聚合表现。
- **实测结果**: Pass。DeepSeek API 成功异步接入且无 UI 乱码方框，滑动窗口违规事件数量聚合展示正常。
