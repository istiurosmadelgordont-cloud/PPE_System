## 3. 测试用例详情

### TC-01: 视频源热切换测试
- **前置条件**: 程序正常运行，摄像头已连接
- **步骤**: 1.点击"导入"导入 MP4 文件 → 2.观察视频播放 → 3.切回实时监控
- **预期结果**: 无缝切换，无卡顿，FPS 稳定

### TC-02: 无感热启动稳定性测试
- **前置条件**: 系统刚启满载运行
- **步骤**: 1.开 htop 监控 CPU 使用 → 2.让系统运行 4 小时
- **预期结果**: Core 2/3 大核占用≤95%，Core 0 小核保持≤55%

### TC-03: PPE 小目标多类别精度测试
- **前置条件**: 模型已加载，量化参数已配置
- **步骤**: 1.输入包含多类 PPE 的测试视频 → 2.统计检测结果
- **预期结果**: 整体 mAP@0.5 ≥ 80%，置信度阈值 0.45 以上

### TC-04: ByteTrack 多目标遮挡追踪测试
- **前置条件**: 推理引擎已启动
- **步骤**: 1.模拟两人交叉遮挡 → 2.观察 Track ID
- **预期结果**: 遮挡后重新出现时 ID 保持一致

### TC-05: 传感器/执行器全链路测试
- **前置条件**: 从核固件已加载
- **步骤**: 1.打火机靠近火焰传感器 → 2.观察蜂鸣器
- **预期结果**: 蜂鸣器启动，UI 出现火警告警

### TC-06: OpenAMP 跨核通信健壮性测试
- **前置条件**: OpenAMP 底层通信路已建好
- **步骤**: 1.拔点电源 → 2.边缘中断触发 → 3.观察恢复
- **预期结果**: 通信恢复，数据不丢失

### TC-07: Qt 渲染流水线性能测试
- **前置条件**: UI 进程启动
- **步骤**: 1.运行系统 → 2.观察 FPS
- **预期结果**: FPS 稳定 ≥ 11.4，画面流畅

### TC-08: 磁盘防击异常注入测试
- **前置条件**: violations_data 目录可写
- **步骤**: 1.填充磁盘至 85% → 2.触发存储 → 3.观察清理
- **预期结果**: 自动删除最旧 20% 图片

### TC-09: 心跳超时断连检测 (FIT)
- **脚本**: `tests/fit_rpmsg_disconnect.sh`
- **步骤**: 停止从核 → 等 15s → 验证检测 → 恢复
- **预期结果**: 主核检测到断连，UI 徽章变红

### TC-10: 主核崩溃安全状态 (FIT)
- **脚本**: `tests/fit_main_crash.sh`
- **步骤**: kill 主进程 → 等 12s → 验证蜂鸣器关闭
- **预期结果**: 从核进入 Fail-Safe，蜂鸣器自动关闭

### TC-11: CRC 数据校验 (FIT)
- **脚本**: `tests/fit_crc_corrupt.sh`
- **步骤**: 发 5 包随机数据 → 验证丢弃
- **预期结果**: CRC 计数增长，系统不崩溃

### TC-12: 模型缺失安全退出 (FIT)
- **脚本**: `tests/fit_model_missing.sh`
- **步骤**: 删模型 → 启动 → 验证退出 → 恢复
- **预期结果**: 打印错误日志，优雅退出

### TC-13: DeepSeek API 断网降级 (FIT)
- **脚本**: `tests/fit_deepseek_offline.sh`
- **步骤**: 断网 → 触发告警 → 验证降级
- **预期结果**: 面板显示预设建议，不影响其他功能
